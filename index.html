Como criar o projeto no Firebase (grátis)
  1. Acesse console.firebase.google.com e crie um projeto.
  2. Em Build → Authentication → Sign-in method, ative E-mail/senha.
  3. Em Build → Firestore Database, crie o banco (modo produção).
  4. Na aba Rules, cole: match /usuarios/{uid} { allow read, write: if request.auth.uid == uid; }
  5. Em Configurações do projeto, registre um app Web e copie o firebaseConfig.
  6. Cole aqui e crie sua conta com e-mail e senha.
